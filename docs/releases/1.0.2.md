# IliasSync 1.0.2

Dieses Update vereinfacht die Installation unter Windows und Ubuntu/Debian und korrigiert die Darstellung außerhalb von macOS.

- **Windows:** Neuer Setup-Assistent installiert die gesamte App für deinen Benutzer, legt einen Startmenü-Eintrag an und registriert die Deinstallation unter „Installierte Apps“. Eine Desktop-Verknüpfung ist optional. Das portable ZIP bleibt verfügbar; vor dem Start vollständig entpacken.
- **Ubuntu/Debian:** Neues DEB-Paket mit App-Menü-Eintrag, Icon und benötigten Systembibliotheken. Über die Paketverwaltung installieren oder `sudo apt install ./IliasSync-1.0.2-Linux-x64.deb` ausführen. Andere Distributionen können weiterhin das portable TAR.GZ verwenden.
- **Windows und Linux:** Fenster, Dialoge und Auswahlmenüs verwenden deckende Flächen statt Transparenz, die dort keinen nativen Hintergrund hatte. Das verhindert durchscheinende und falsch gemischte helle/dunkle Inhalte.
- **Fehlerhinweise:** Die Beschreibung steht direkt unter und links bündig mit der Statusüberschrift; Uhrzeit und Zeitplan folgen darunter.
- **GitHub:** Die Hauptvorschau zeigt die App immer im Darkmode.

Installer und DEB enthalten Python und Qt. Installationsprüfungen auf nativen CI-Runnern kontrollieren die installierte Runtime, eine erneute Installation und die Deinstallation. Materialien und Einstellungen liegen außerhalb der Installation und werden beim Entfernen der App behalten. Vor einer dauerhaften Deinstallation die Automatik in der App ausschalten. Beim Wechsel vom portablen Paket den Zeitplan am neuen Installationsort erneut speichern.

macOS 13+ (Apple Silicon/Intel), Windows 10/11 x64 und Linux x64 mit glibc 2.35+. Das DEB richtet sich an Ubuntu 22.04+ und kompatible Debian-Systeme. macOS-Pakete sind ad-hoc signiert, aber nicht notarisiert; Windows-App und Installer haben keine Authenticode-Signatur. Kein automatischer Updater.

Alle Pakete und `SHA256SUMS` stehen unten. [Installation](https://github.com/schroedernils/ilias-sync/blob/v1.0.2/docs/INSTALLATION.md) · [Prüfgrenzen](https://github.com/schroedernils/ilias-sync/blob/v1.0.2/docs/VERIFICATION.md)
