# IliasSync 1.0.3

Dieses Update hält deinen eingerichteten Sync-Zeitplan nach Updates, Neuinstallationen und einem Wechsel des Installationsorts funktionsfähig.

- Beim App-Start wird ein eingeschalteter Zeitplan mit der aktuellen Installation abgeglichen. Ein fehlender Systemauftrag oder ein alter Programmpfad wird mit dem gespeicherten Wochenplan, den täglichen Zeiten oder dem Intervall repariert.
- Ein intakter Zeitplan wird nicht neu angelegt. Eine bewusst ausgeschaltete Automatik bleibt aus.
- **Einstellungen → Zeitplan → Speichern** repariert den Systemauftrag auch dann, wenn du keine Uhrzeit geändert hast.
- Ist die Aufgabenplanung nicht verfügbar, bleiben alle Uhrzeiten gespeichert. **Zeitplan prüfen** führt direkt zu den Einstellungen für einen erneuten Versuch.
- Installer-Prüfungen kontrollieren zusätzlich den unveränderten Wochenplan nach Installation und Deinstallation. Windows prüft auch die echte Aufgabenplanung einschließlich erneutem Start ohne doppelte Registrierung.

Installiere das Update und öffne die App einmal. Deine Hochschulen, Materialien, Passwörter und Zeitplan-Einstellungen bleiben erhalten. Ein absichtliches Entfernen sämtlicher App-Benutzerdaten ist ein vollständiger Reset und benötigt eine vorherige Datensicherung.

**Mac mit M-Chip:** das native `macOS-arm64.dmg` verwenden; Rosetta ist nicht nötig. `macOS-x64.dmg` ist für Intel-Macs. Windows bietet den Setup-Assistenten, Ubuntu/Debian das DEB-Paket; portable Archive bleiben verfügbar. System- und Signaturgrenzen entsprechen 1.0.2: keine macOS-Notarisierung und keine Windows-Authenticode-Signatur.
