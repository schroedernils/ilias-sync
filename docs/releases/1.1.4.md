IliasSync 1.1.4 makes course-link problems easier to fix. Regular course materials can keep syncing even when a previously saved link points to external content.

- **Clearer sync recovery.** If a saved link cannot be used as a course, select **Review course links** from the sync status. IliasSync skips the link and keeps your downloaded files. A real sign-in problem still offers sign-in renewal.
- **Manage manually added links.** See the saved address, edit it, or remove it under **Choose courses**. The dialog explains why a web link or individual file cannot be added as a course.
- **Quieter setup on Mac.** The setup counter uses a compact `1/3` format. Window surfaces are slightly more opaque, with a subtle backdrop in setup and sign-in dialogs.

External destinations, including GitHub Release downloads, are not mirrored as course files in this version.
