# IliasSync 1.1.0

IliasSync can now check for new app versions and guide you through installing them, using the official GitHub releases.

- **macOS:** native update dialogs, optional automatic checks and a separate option to download and install updates automatically.
- **Windows:** native update checks and installation through the existing Setup wizard.
- **Linux:** on supported DEB installations, download and verify the update, then choose **Install update** to open your package manager. Portable installations retain a link to the release page.
- **Your choice:** configure automatic checks under **Settings → Updates**, or use **Check for app updates** from the app menu on macOS or Help on Windows/Linux. Automatic checks require your consent.
- **Verified downloads:** update packages carry Ed25519 signatures. The Mac update feeds and Linux metadata are signed as well. Incorrect or modified downloads are rejected.
- **Your library stays:** materials, university connections and the saved synchronization schedule remain in their existing locations. App-update preferences are separate from synchronization settings.

**Upgrading from 1.0.4 or earlier:** install 1.1.0 once using the normal download. Earlier releases do not contain the updater and cannot acquire it automatically. Open the new app once, then choose whether to enable automatic update checks. You do not need to repeat onboarding.

Mac with Apple Silicon: choose `macOS-arm64.dmg`. Intel Mac: choose `macOS-x64.dmg`. Windows: choose `Windows-x64-Setup.exe`. Ubuntu/Debian x64: choose `Linux-x64.deb`.

Update signatures do not replace Apple notarization or Windows Authenticode certificates; existing operating-system trust warnings may still appear. Linux installation can require package-manager authorization. Automatic checks run while the app is open.
