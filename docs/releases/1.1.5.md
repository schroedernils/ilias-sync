IliasSync 1.1.5 makes it easier to find a complete set of exercise sheets, lecture slides, and earlier versions in one place.

- **Materials stay together.** When ILIAS links the same file from a course material folder and a dated session, IliasSync uses the material folder. Existing unmodified downloads can move there if the destination is free. Files that ILIAS stops listing stay available in their folder and are marked **Kept locally** after a complete check.
- **Find sheets by number.** Within a course, materials are sorted in numeric filename order. Use the folder filter to browse a single exercise collection or lecture folder.
- **Open earlier versions.** Select **Versions** on a file to see the current copy and locally saved versions with dates and sizes. Older archive files are still available in the archive folder.
- **Keep downloads distinct and names readable.** Submissions and feedback for different assignments keep separate entries. Identical local files can be reused without taking ownership. An unmodified IliasSync copy regains its ordinary name when the name is available.

The new folder placement applies at the next sync. Your explicit destination rules still take priority.
