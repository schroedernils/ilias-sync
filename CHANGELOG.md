# Changelog

## 0.1.0a2 — 2026-10-22

Preserve the main workspace layout; replace setup with three focused steps and group settings by appearance and synchronization. Complete system-following light/dark palettes, optional overrides, live scheme changes, wide fields and readable scroll surfaces. Active runs expose accessible pause/resume symbols and a red stop control, including OS-scheduled runs observed while the app is open. Cancellation occurs at safe async boundaries and does not interrupt an atomic file publication. Paused time is excluded from the worker deadline. Course selection shows counts, search and an explicit scrollbar; read-only membership overview pagination is followed. Folder mapping supports course, subfolder and file destinations with most-specific precedence, keeping prior copies after reassignment. Stronger headings and a compact empty workspace. The owner-supplied icon now replaces the placeholder in the UI, native bundles and Windows executable; Linux includes an optional desktop launcher. Settings gains a bilingual Info tab with usage, platform and privacy boundaries and reference links. Schema 1 gains optional profile rules and manifest metadata; existing profiles remain readable.

## 0.1.0a1 — 2026-10-22

First private preview: configurable ILIAS sources, Qt desktop UI, standard login and guarded SSO/session import, course selection/discovery, incremental downloads, archive/version/conflict protection, battery-aware native scheduling, headless one-shot jobs, tests and four native build targets across three operating systems. Schema 1. No migration from the earlier personal Google Drive script; that installation remains separate.
